# Stremio Search

A Flow Launcher plugin for searching and launching Stremio movies and TV shows.

## Usage

`sm <query>`

Search your Stremio library and Stremio catalog.

## Power User Mode

Enable "Require '?' for online catalog search" in plugin settings.

- `sm dune` local library search (no api calls made to cinemeta)
- `sm dune?`  online Stremio catalog search
